# OmaChat v0.3.1

This patch release restores offline buildability for the vendored Telegram
client by including the required `gotd/td/bin` package.

All OmaChat v0.3.0 capabilities remain unchanged, including Google Messages,
WhatsApp, Telegram text and media support, voice notes, and static WebP
stickers. Animated TGS and video stickers remain unsupported.

AI tools assisted with development and documentation. Authorship and
maintenance remain with the human project contributors.
